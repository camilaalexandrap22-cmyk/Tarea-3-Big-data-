## Descripción del repositorio
Este repositorio contiene la implementación práctica del análisis batch y el procesamiento en streaming utilizando herramientas de Big Data.

- **`batch/`**: Contiene los scripts y análisis de procesamiento por lotes.
- **`streaming/`**: Contiene los flujos de datos en tiempo real (ej. productores/consumidores de Kafka).
